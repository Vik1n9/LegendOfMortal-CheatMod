# 「事件攻略」分頁規格

## 目標

在「唐門密卷」視窗「戰鬥養成」之後新增「事件攻略」分頁。依據**目前遊戲日期**與**角色各項參數**，提醒玩家：

1. 哪些事件本旬已滿足條件、會觸發；
2. 哪些事件時間已到（或即將到）但條件不足，缺少哪些關鍵參數；
3. 只列事件名稱與條件狀態，不顯示劇情內容。

事件清單與條件來源：活俠傳 wiki〈主支線簡易表格〉及其各事件條目的「觸發條件」欄
（https://smilin.net/LoM-wiki/event/story-simple-table.html ）。

## 分頁位置

`骰子選項／屬性銀兩／戰鬥養成／事件攻略／事件任務／系統`
（原「事件任務」「系統」順延一格。）

## 版面

```
目前狀況 ─────────────────────────────
  第二年 三月 上旬　·　路線：崆峒留學　·　行動點 3
  心相 45　修養 60　性情 30　處世 20　道德 50　學問 40
  名聲 12　門派規模 2　貢獻度 35
  [✓] 顯示即將開始（未來 6 旬）

本旬可觸發 ─────────────────────────────
  ┌ 崆峒留學                                   ┐
  ┌ 鐵拳巷事件集                                ┐
  │ 另需：點選「鐵拳巷」                          │

條件不足 ─────────────────────────────
  ┌ 崆峒探險隊                                  ┐
  │ 缺：虞小梅好感 12（需 ≥20）、瑞笙好感 3（需 ≥7）│
  │ 已達：認識小梅                               │

即將開始 ─────────────────────────────
  ┌ 衣服遭竊　　　　　　　　　　　　 第二年四月上旬 ┐
  │ 缺：崆峒門派＝奪魄門                          │
```

- 每個事件一張卡片：第一行事件名稱（即將開始的另顯示開始時間），第二行起列出條件。
- 未達成的條件用紅字列在「缺：」，已達成用綠字列在「已達：」，無法由程式判定的條件用灰字列在「另需：」。
- 三個區段都沒有事件時顯示「目前沒有對應事件」。
- 尚未進入遊戲（無存檔資料）時顯示「請先載入存檔」。

## 判定規則

### 時間

- 遊戲時間換算為旬序：`(年-1)*36 + (月-1)*3 + 旬(1~3)`，與遊戲 `GameTime.ConvertToRounds()` 一致。
- 每個事件有開始、結束旬序。wiki 有寫時間區間者（如「第一年九月中旬～第二年四月下旬」）用該區間；沒寫者以表格所在旬為開始＝結束。
- 目前旬序在區間內 → 進入判定；早於開始且差距 ≤ 6 旬 → 「即將開始」；已過結束 → 不顯示。
- 「不限時間」事件（如四師兄閒聊、變心夢）視為整局區間。

### 路線

由遊戲旗標判定玩家路線，與事件路線不符者不顯示：

| 路線 | 判定 |
|---|---|
| 崆峒留學 | `M20008`（留學）＝2 |
| 青城留學 | `M20008`＝1 |
| 不留學住客棧 | `M20028`（離家出走路線）＝2 |
| 不留學住破廟 | `M20028`＝1 且 `M20008`≠1 |
| 遣散唐門（退隱線） | `M70015`（你的決策）＝1 |
| 頑抗到底（不成立西武林） | `M70015`＝2 或 3 |
| 成立西武林 | `M70015`＝4 |

- 尚未分歧時（旗標為 0）視為各路線皆可能，事件照常列出，路線欄顯示「未定」。
- 住破廟者在第二年八月前仍可能轉入青城留學，故破廟、青城兩線的事件都列出。
- 無可救藥（Demo 線）事件不收錄。

### 條件種類

| 種類 | 來源 | 範例 |
|---|---|---|
| 數值 | `PlayerStatManagerData.Stats` | 心相（心理衛生）≤30、修養≥80、名聲≥10、貢獻度<0、行動次數≥2 |
| 好感 | `PlayerStatManagerData.Relationships` | 四師兄好感≥15、虞小梅好感≥20 |
| 旗標 | `MissionManagerData.GetFlag(id).State` | 收留葉氏兄妹（M10001）、葉雲裳在唐門（E12000）、攻略小竹（G11006） |
| 任一 | 多個條件取其一 | 小梅投靠：虞小梅好感≥35 或 小竹在唐門 |
| 備註 | 無法由程式判定 | 「點選鐵拳巷」「接續某事件」「擲骰結果」 |

- 旗標 ID 由遊戲資源中的 `FlagData` 名稱與開發註記對照取得，只採用意義明確對應 wiki 描述者；對應不明確的條件一律寫成「備註」，不猜測。
- 「XX在唐門」類旗標以遊戲原生的「XX不在唐門」反向判定（例：四師兄在唐門＝`E10005`＝0）。
- 好感以星數描述者（如「唐陞好感≥2.5星」）換算不明，列為備註。

### 狀態

| 狀態 | 條件 |
|---|---|
| 本旬可觸發 | 在時間內、路線相符，所有可判定條件都成立 |
| 條件不足 | 在時間內、路線相符，至少一個可判定條件不成立 |
| 即將開始 | 開始時間在未來 6 旬內、路線相符（同樣列出條件達成狀況，方便提前準備） |

只有「備註」條件的事件會落在「本旬可觸發」，並以「另需」提示玩家自行確認。

## 已知限制

- 「一次性事件」是否已觸發過，多數沒有可靠旗標，無法排除已看過的事件。
- 「接續某事件」「擲骰結果」「選項分歧」等劇情前置無法判定，只以備註提示。
- 條件內容依 wiki 撰寫時版本，遊戲改版後可能需要更新 `EventGuideData.cs`。

## 實作

| 檔案 | 內容 |
|---|---|
| `Core/EventGuide.cs` | 條件型別（數值／好感／旗標／任一／備註）、路線判定、事件狀態計算 |
| `Core/EventGuideData.cs` | 事件清單（名稱、時間區間、路線、條件），依 wiki 整理 |
| `UI/CheatWindow.cs` | 新增「事件攻略」分頁與 `DrawGuide()` |

- 判定結果每 1 秒重算一次（OnGUI 每幀會呼叫，避免每幀查旗標）。
- 全部只讀取遊戲資料，不修改任何數值。
- 讀取失敗（例如在標題畫面）時捕捉例外並顯示「請先載入存檔」。

# 路線地圖與結局圖鑑（v1.3 規劃）

「事件攻略」分頁改為三個子頁：`路線地圖`／`本旬事件`／`結局圖鑑`。`本旬事件`即上文的平面清單，其餘為新增。

## 路線地圖

由上而下的時間軸，分成四段（第一年／第二年留學與離家的分歧／第二年末～第三年／第三年十二月起三條路線）。
每段有 5 條欄位（Lane），例如第二年分成「崆峒留學・不留學客棧・唐門・不留學破廟・青城留學」。

| 元素 | 說明 |
|---|---|
| 米色方塊 | 一般事件 |
| 金黃底方塊 | **分歧點**：副標題顯示「◆分歧 N 條路」；玩家已選時（遊戲旗標可判定者）顯示「✔ 選項名稱」 |
| 紅底方塊 | 結局群組（退隱／頑抗到底／西武林盟），點開列出該線結局 |
| 朱紅外框＋「◀目前／◀下一步」 | 依遊戲日期與路線找出的目前節點；「定位到目前」按鈕會捲到此處 |
| 淡色方塊 | 不在玩家目前路線上（路線判定同上文「路線」表） |
| 灰色方塊 | 已經過去 |
| 連線 | 節點往下連到後續節點；已選的路用朱紅色，與選取節點相連的線用墨色加粗 |

點選方塊會在地圖上方顯示詳情：時間、觸發地點／方式、相關旗標（即時判定：紅＝缺、綠＝已達、灰＝程式無法判定）、
備註，以及**每個選項**的解鎖條件、結果與去向（去向可直接點選跳到該節點或結局）。

### 資料來源與原則

- `Core/GuideMapData.cs`：節點與選項。來源為 wiki〈主支線簡易表格〉各事件頁、〈眾人的決策〉、〈武林盟對策〉等。
- `Core/GuideEndings.cs`：66 個結局，由 wiki〈汗青書〉列表轉出（名稱、標籤、條件概要）。
- wiki 有寫明數值的條件才寫成可判定條件（如「道德≥40」）；沒寫清楚、或需要遊戲內部才知道的（如「心上人是誰」「戰術等級」）一律寫成灰字備註，不猜測。
- 結局的 `Route` 由 wiki 標籤推得（破廟線／青城留學／遣散唐門／唐門覆滅／西武林盟）；`Deadline` 為最晚決定時間，過了就標示「已錯過」。沒有把握的結局不設期限、路線設為任何路線。

### 主要分歧（目前收錄）

1. 壽禮擲骰（≥80 南宮仇人線）→ 南宮壽宴（結局7）
2. 留學討論：崆峒留學／退席（不留學）
3. 崆峒門派抽籤（鐵拳／玄功／奪魄／飛天）→ 江陵決戰（玄功傳承：加入／拒絕崆峒）
4. 離家出走：住破廟／住客棧（葉雲裳在唐門且好感≥30 時強制轉住破廟）
5. 破廟密謀：報信／先考慮再報信／跑路（結局21）／攻打唐門（結局4）
6. 唐門迎敵後：葉雲裳在唐門且心上人為葉雲裳 → 青城留學；否則留在唐門
7. 青城醒轉：讓申屠龍把脈／戰申屠龍（結局53）
8. 臥雲崗：下山／留守（影響金烏上人死亡與西武林青城支持）
9. 四師兄離去（結局12～15、55）、金烏鬧事（結局16、22）、雪山行、錦香宮
10. 眾人的決策：戰他娘親／退隱江湖／西武林盟 → 出使丐幫、青城、峨嵋、崆峒 → 唐門圍攻戰／東西武林盟會戰

## 結局圖鑑

列出全部結局的名稱、標籤、條件概要與程式可判定的條件（結緣旗標 `G11000/11002/11004/11005/11006`）。
預設只顯示「仍可達成」（排除已錯過、不在目前路線、目前版本無法達成者），可切換為全部。

## 驗證

遊戲 DLL 不在開發環境時，可用 `tools/guide-verify`（型別替身專案，`dotnet run --project tools/guide-verify`）編譯 `Core` 與 `UI/GuideMapView.cs`，並檢查：
節點 Id 不重複、所有去向存在、連線一律向下、連線不穿過其他節點、每個節點皆可由起點到達、結局編號完整（66 個）。

### 與遊戲本體比對

`tools/game-extract/extract.py` 會從本機遊戲的 Unity 資產抽出完整事件判定（任務檢查點的時間／地點／條件樹、旗標值域、
汗青書編號與名稱、劇本開啟的結局），輸出到 `tools/game-extract/out/`（內含遊戲資料，已列入 .gitignore，**不可提交**；沒有遊戲時 guide-verify 只跑第一層檢查）。
`tools/guide-verify` 讀到這份資料後會多檢查：旗標是否存在、`FlagIs` 的值域說明是否與遊戲一致、結局名稱是否相符、
「目前無法達成」的結局是否其實有劇本會開啟、節點時間是否對得上任務檢查點、遊戲任務收錄率，
並用旗標＋日期跑煙霧測試確認目前節點。`WARN` 代表 wiki 與遊戲腳本說法不同，需人工確認。
