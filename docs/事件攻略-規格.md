# 「事件攻略」分頁規格

## 目標

在「唐門密卷」視窗「戰鬥養成」之後新增「事件攻略」分頁。依據**目前遊戲日期**與**角色各項參數**，提醒玩家：

1. 哪些事件本旬已滿足條件、會觸發；
2. 哪些事件時間已到（或即將到）但條件不足，缺少哪些關鍵參數；
3. 只列事件名稱與條件狀態，不顯示劇情內容。

事件清單與條件來源：活俠傳 wiki〈主支線簡易表格〉及其各事件條目的「觸發條件」欄
（https://smilin.net/LoM-wiki/event/story-simple-table.html ）。

## 分頁位置

`骰子選項／屬性銀兩／戰鬥養成／事件攻略／事件任務／系統`
（原「事件任務」「系統」順延一格。）

## 版面

```
目前狀況 ─────────────────────────────
  第二年 三月 上旬　·　路線：崆峒留學　·　行動點 3
  心相 45　修養 60　性情 30　處世 20　道德 50　學問 40
  名聲 12　門派規模 2　貢獻度 35
  [✓] 顯示即將開始（未來 6 旬）

本旬可觸發 ─────────────────────────────
  ┌ 崆峒留學                                   ┐
  ┌ 鐵拳巷事件集                                ┐
  │ 另需：點選「鐵拳巷」                          │

條件不足 ─────────────────────────────
  ┌ 崆峒探險隊                                  ┐
  │ 缺：虞小梅好感 12（需 ≥20）、瑞笙好感 3（需 ≥7）│
  │ 已達：認識小梅                               │

即將開始 ─────────────────────────────
  ┌ 衣服遭竊　　　　　　　　　　　　 第二年四月上旬 ┐
  │ 缺：崆峒門派＝奪魄門                          │
```

- 每個事件一張卡片：第一行事件名稱（即將開始的另顯示開始時間），第二行起列出條件。
- 未達成的條件用紅字列在「缺：」，已達成用綠字列在「已達：」，無法由程式判定的條件用灰字列在「另需：」。
- 三個區段都沒有事件時顯示「目前沒有對應事件」。
- 尚未進入遊戲（無存檔資料）時顯示「請先載入存檔」。

## 判定規則

### 時間

- 遊戲時間換算為旬序：`(年-1)*36 + (月-1)*3 + 旬(1~3)`，與遊戲 `GameTime.ConvertToRounds()` 一致。
- 每個事件有開始、結束旬序。wiki 有寫時間區間者（如「第一年九月中旬～第二年四月下旬」）用該區間；沒寫者以表格所在旬為開始＝結束。
- 目前旬序在區間內 → 進入判定；早於開始且差距 ≤ 6 旬 → 「即將開始」；已過結束 → 不顯示。
- 「不限時間」事件（如四師兄閒聊、變心夢）視為整局區間。

### 路線

由遊戲旗標判定玩家路線，與事件路線不符者不顯示：

| 路線 | 判定 |
|---|---|
| 崆峒留學 | `M20008`（留學）＝2 |
| 青城留學 | `M20008`＝1 |
| 不留學住客棧 | `M20028`（離家出走路線）＝2 |
| 不留學住破廟 | `M20028`＝1 且 `M20008`≠1 |
| 遣散唐門（退隱線） | `M70015`（你的決策）＝1 |
| 頑抗到底（不成立西武林） | `M70015`＝2 或 3 |
| 成立西武林 | `M70015`＝4 |

- 尚未分歧時（旗標為 0）視為各路線皆可能，事件照常列出，路線欄顯示「未定」。
- 住破廟者在第二年八月前仍可能轉入青城留學，故破廟、青城兩線的事件都列出。
- 無可救藥（Demo 線）事件不收錄。

### 條件種類

| 種類 | 來源 | 範例 |
|---|---|---|
| 數值 | `PlayerStatManagerData.Stats` | 心相（心理衛生）≤30、修養≥80、名聲≥10、貢獻度<0、行動次數≥2 |
| 好感 | `PlayerStatManagerData.Relationships` | 四師兄好感≥15、虞小梅好感≥20 |
| 旗標 | `MissionManagerData.GetFlag(id).State` | 收留葉氏兄妹（M10001）、葉雲裳在唐門（E12000）、攻略小竹（G11006） |
| 任一 | 多個條件取其一 | 小梅投靠：虞小梅好感≥35 或 小竹在唐門 |
| 備註 | 無法由程式判定 | 「點選鐵拳巷」「接續某事件」「擲骰結果」 |

- 旗標 ID 由遊戲資源中的 `FlagData` 名稱與開發註記對照取得，只採用意義明確對應 wiki 描述者；對應不明確的條件一律寫成「備註」，不猜測。
- 「XX在唐門」類旗標以遊戲原生的「XX不在唐門」反向判定（例：四師兄在唐門＝`E10005`＝0）。
- 好感以星數描述者（如「唐陞好感≥2.5星」）換算不明，列為備註。

### 狀態

| 狀態 | 條件 |
|---|---|
| 本旬可觸發 | 在時間內、路線相符，所有可判定條件都成立 |
| 條件不足 | 在時間內、路線相符，至少一個可判定條件不成立 |
| 即將開始 | 開始時間在未來 6 旬內、路線相符（同樣列出條件達成狀況，方便提前準備） |

只有「備註」條件的事件會落在「本旬可觸發」，並以「另需」提示玩家自行確認。

## 已知限制

- 「一次性事件」是否已觸發過，多數沒有可靠旗標，無法排除已看過的事件。
- 「接續某事件」「擲骰結果」「選項分歧」等劇情前置無法判定，只以備註提示。
- 條件內容依 wiki 撰寫時版本，遊戲改版後可能需要更新 `EventGuideData.cs`。

## 實作

| 檔案 | 內容 |
|---|---|
| `Core/EventGuide.cs` | 條件型別（數值／好感／旗標／任一／備註）、路線判定、事件狀態計算 |
| `Core/EventGuideData.cs` | 事件清單（名稱、時間區間、路線、條件），依 wiki 整理 |
| `UI/CheatWindow.cs` | 新增「事件攻略」分頁與 `DrawGuide()` |

- 判定結果每 1 秒重算一次（OnGUI 每幀會呼叫，避免每幀查旗標）。
- 全部只讀取遊戲資料，不修改任何數值。
- 讀取失敗（例如在標題畫面）時捕捉例外並顯示「請先載入存檔」。
